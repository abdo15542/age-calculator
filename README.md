# 🎂 حاسبة العمر — تطبيق Android

تطبيق Android حقيقي (Capacitor) لحساب العمر بالكامل، بالعربية وباتجاه RTL.
اكتب تاريخ ميلادك (ووقت الولادة اختياريًا) وستظهر لك لوحة حياتك كاملة:

- عمرك الدقيق بالسنوات والأشهر والأيام مع **عدّاد ثوانٍ حيّ**
- إجمالي الأشهر والأسابيع والأيام والساعات والدقائق والثواني
- يوم ميلادك، وتاريخه بالهجري، وبرجك الفلكي والصيني، وجيلك، وفصل ميلادك
- عدّاد عيد ميلادك القادم مع نسبة ما انقضى من سنتك الحالية
- محطات عمرية (١٠٠٠ أسبوع، ١٠٬٠٠٠ يوم، مليار ثانية...)
- عمرك على الكواكب الأخرى وإحصاءات حياة تقديرية
- وضع ليلي ومشاركة ملخص عمرك نصيًا

البيانات تُحفظ محليًا على الهاتف فقط (localStorage)، والتطبيق يعمل **بالكامل دون إنترنت وبدون أي ذكاء اصطناعي** — كل الحسابات محلية فورية، ولا يُرسَل أي شيء لأي خادم.

## البناء

```bash
npm ci
npx cap sync android
cd android && ./gradlew assembleDebug
```

يتطلب JDK 21 وAndroid SDK.
